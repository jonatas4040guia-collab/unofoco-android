# Unofoco para Android

O APK do Unofoco para instalar fora da Play Store.

**Baixe e veja como instalar em [app.unofoco.com.br/baixar](https://app.unofoco.com.br/baixar).**

- Cada versão fica em [Releases](../../releases), com a impressão digital (SHA-256) do arquivo.
- O APK daqui e o da Play Store são o mesmo app com assinaturas diferentes: um não atualiza o outro. Para trocar, desinstale o que está no celular (espere sincronizar antes) e instale o outro.
- No iPhone e no computador, use o app web: [app.unofoco.com.br](https://app.unofoco.com.br).

Só os arquivos de instalação ficam aqui; o código do app não.
